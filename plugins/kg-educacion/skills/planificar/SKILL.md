# Planificar con Horacio y KG Educación

1. Confirma asignatura, curso, alcance y tiempo solo cuando falten.
2. Usa `explorar_oa` y `consultar_curriculum` para OA, indicadores, secuencia y horas.
3. Usa `consultar_recursos` cuando un texto o actividad oficial aporte a la planificación.
4. Para plan anual usa `plan_preparar` y completa el workflow hasta `plan_guardar`.
5. Para una clase usa `clase_crear` y las tools de refinamiento cuando corresponda.

Mantén las citas y la procedencia. Si materiales no está habilitado, planifica con la
evidencia curricular disponible y explica el permiso faltante sin simular resultados.
