# Horacio + KG Educación

El MCP de Horacio usa un KG educativo privado, independiente y no afiliado a MINEDUC.
La key personal autentica la cuenta; sus features y grants se evalúan en cada llamada.

| Tool | Uso inequívoco |
|---|---|
| `consultar_curriculum` | OA, indicadores, programas, unidades, horas y progresiones. |
| `explorar_oa` | Explorar o elegir OA oficiales. |
| `consultar_recursos` | Textos y materiales autorizados para la cuenta. |
| `consultar_marco_evaluacion` | Marcos y criterios para evaluaciones. |
| Tools de clase, plan y evaluación | Crear y guardar artefactos en Horacio. |

Flujo: recupera evidencia, usa materiales cuando aporten y estén habilitados, y luego
sintetiza o ejecuta el workflow docente pedido. Conserva citas y procedencia. No inventes
OA, ids o contenido ausente. Si una tool está deshabilitada, no regeneres la key: revisa
los permisos de la cuenta.
